# Studio3D و «التحكم الذكي في التطبيقات» (Smart App Control)

## لماذا تحظر الحماية البرامج الخاصة؟
Smart App Control يسمح فقط بالبرامج **الموقّعة رقمياً** أو **المعروفة لدى مايكروسوفت**. أي ‎`.exe` أو ‎`.dll` تصنعه بنفسك غير موقّع وغير معروف ← يُحظر. كذلك يحظر الملفات النصية التنفيذية (`.bat` / `.ps1` / `.cmd`) **إذا نُزّلت من الإنترنت عبر المتصفح**.

## كيف تجنّب Studio3D ذلك
| الخطر | الحل في Studio3D |
|---|---|
| ‎`.exe` خاص بالبرنامج | لا يوجد. التشغيل عبر `python.exe` الرسمي (موقّع من Python Software Foundation) |
| مكتبة DLL مُجمّعة خاصة (`custom_rasterizer`) | أُعيدت كتابتها ببايثون/PyTorch فقط — `studio3d/vendor/custom_rasterizer` |
| ‎`pip.exe` وأدوات Scripts غير الموقّعة | لا نستخدمها: دائماً `python -m pip` |
| ملفات منزّلة من المتصفح (علامة الإنترنت MotW) | التثبيت بأمر `irm … \| iex` — لا يمر شيء عبر المتصفح |
| نافذة البرنامج | Microsoft Edge بوضع التطبيق (موقّع من مايكروسوفت) |
| ملف التشغيل `Studio3D.cmd` | يُنشأ محلياً على جهازك، لذلك لا يحمل علامة الإنترنت |

## ما الذي قد يبقى؟
ملفات ‎`.pyd` داخل مكتبات بايثون المشهورة (numpy، torch، opencv…). معظمها له سمعة جيدة لدى مايكروسوفت لأنها مُنزّلة ملايين المرات. إذا حُظر أحدها، فأداة الفحص تحدده بالاسم:

```
تبويب «الجهاز» ← «فحص الحماية»
```
أو من PowerShell:
```powershell
cd $env:LOCALAPPDATA\Studio3D\app; ..\python\tools\python.exe -m studio3d.sac_check
```

## الحلول إذا ظهر حظر
1. **أعد تشغيل أمر التثبيت.** إذا حُظر ملف أثناء التثبيت الأول، لأن خدمة التحقق من السمعة لم تكن متاحة وقتها، يُعاد تنزيله بنسخته الرسمية.
2. **توقيع الشركة (الحل الاحترافي):** اشترِ شهادة توقيع كود (Code Signing) باسم الشركة بمفتاح RSA، لأن Smart App Control لا يقبل حالياً شهادات ECC. بعدها وقّع الملفات المحظورة فقط بالأداة `signtool sign /fd sha256 /tr http://timestamp.digicert.com /td sha256 /f company.pfx <file>`. نضيف ذلك تلقائياً للمثبّت عند توفر الشهادة.
3. **الحل الأخير:** «أمان Windows» ← «التحكم في التطبيقات والمتصفح» ← «Smart App Control» ← إيقاف. منذ تحديث ويندوز 11 لشهر أبريل 2026 (KB5083769) يمكن إعادة تشغيله لاحقاً بدون إعادة تثبيت ويندوز.
   - ⚠️ ملاحظة: تحديث أكتوبر 2026 (KB5127648) فيه مشكلة معروفة قد تمنع إعادة التشغيل مؤقتاً على بعض الأجهزة. لذلك اترك هذا الحل للأخير.
